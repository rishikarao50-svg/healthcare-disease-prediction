# 🏥 Healthcare Multiple Disease Risk Prediction

## 📌 Project Overview

Healthcare Multiple Disease Risk Prediction is a machine learning-based web application developed using Python and Streamlit. It predicts the potential risk of four diseases based on user-provided health information.

The application allows users to select a disease, enter relevant health parameters, and receive a risk prediction generated by a trained machine learning model.

## 🎯 Objectives

- Develop a user-friendly healthcare risk prediction application.
- Apply machine learning models to multiple disease prediction tasks.
- Collect relevant health parameters through an interactive web interface.
- Display prediction results in an understandable format.
- Demonstrate the application of machine learning in healthcare analytics.

## 🦠 Diseases Covered

The application supports the following four prediction modules:

| Disease | Input Parameters |
|---|---|
| Heart Disease | Age, systolic blood pressure, diastolic blood pressure, cholesterol, BMI, heart rate |
| Diabetes | Age, glucose level, HbA1c, BMI, systolic blood pressure |
| Kidney Disease | Age, systolic blood pressure, glucose level, creatinine, hemoglobin |
| Liver Disease | Age, bilirubin, ALT, AST, albumin |

## ✨ Features

- **Multiple Disease Prediction:** Select one of four disease categories.
- **Interactive User Interface:** Enter health parameters using Streamlit input fields.
- **Machine Learning Integration:** Load trained models and generate predictions.
- **Risk Classification:** Display higher-risk or lower-risk results.
- **Real-Time Interaction:** Generate a prediction when the user clicks the corresponding button.
- **Modular Design:** Maintain a separate trained model for each disease.

## 🛠️ Technologies Used

- **Programming Language:** Python
- **Web Framework:** Streamlit
- **Machine Learning:** Scikit-learn-compatible trained models
- **Numerical Processing:** NumPy
- **Model Serialization:** Pickle

## ⚙️ Installation and Setup

### Prerequisites

- Python 3.9 or a compatible Python version.
- pip package manager.
- The four trained model files (`.pkl`).

### Step 1: Clone the repository

```bash
git clone <your-github-repository-url>
```

Navigate to the project directory:

```bash
cd Healthcare-Multiple-Disease-Prediction
```

### Step 2: Create a virtual environment (recommended)

```bash
python -m venv venv
```

Activate it on Windows:

```bash
venv\Scripts\activate
```

On macOS or Linux:

```bash
source venv/bin/activate
```

### Step 3: Install dependencies

Create a `requirements.txt` file with the following contents:

```text
streamlit
numpy
scikit-learn
```

Install the dependencies:

```bash
pip install -r requirements.txt
```

Use the same compatible scikit-learn version that was used to train the models, if applicable.

### Step 4: Add the trained models

Ensure that these files are present in the same directory as `app.py`:

- `heart_model.pkl`
- `diabetes_model.pkl`
- `kidney_model.pkl`
- `liver_model.pkl`

The application cannot run its predictions without these files.

### Step 5: Run the application

```bash
streamlit run app.py
```

Streamlit will display a local URL in the terminal, usually:

```text
http://localhost:8501
```

Open the URL in your browser to use the application.

## 🔄 How It Works

1. **Launch:** The Streamlit application loads the four serialized machine learning models.
2. **Select Disease:** The user selects Heart Disease, Diabetes, Kidney Disease, or Liver Disease.
3. **Enter Health Information:** The application displays the input fields relevant to the selected disease.
4. **Prepare Input:** The entered values are arranged into a NumPy array in the expected feature order.
5. **Predict:** The corresponding model's `predict()` method generates a class prediction.
6. **Display Result:** The application displays a higher-risk or lower-risk message based on the predicted class.

## 🧠 Machine Learning Approach

The application uses supervised machine learning models trained for binary classification.

Each model receives a set of health parameters and predicts one of two classes:

- `1`: Displayed as higher risk.
- `0`: Displayed as lower risk.

The actual model algorithms, training datasets, preprocessing procedures, and evaluation metrics depend on how the individual models were developed. They are not specified in the application code.

## ⚠️ Limitations and Disclaimer

- This project is intended for educational and demonstration purposes only.
- The predictions are not medical diagnoses and must not replace professional medical advice.
- Prediction quality depends on the training data, model performance, and correct input formatting.
- The models must be trained using features in exactly the same order and with compatible preprocessing.
- The application currently displays class predictions rather than calibrated risk probabilities.
- Synthetic data, if used for training, may not represent real-world patient populations.
- Pickle files should only be loaded from trusted sources because loading untrusted serialized files can execute malicious code.
- The application has not been established as a clinically validated medical tool.
